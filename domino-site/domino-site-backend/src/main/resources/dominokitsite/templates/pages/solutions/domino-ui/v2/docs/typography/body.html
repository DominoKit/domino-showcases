Font scope

Domino UI uses CSS custom properties for typography. The default body font is Source Sans 3, and the component typography tokens derive from --dui-font-family-body and --dui-font-family-heading.

Use dui-font-scope when a font should apply only to one application area, preview, or embedded component tree. The scope recalculates the body and heading font variables for that element and applies the selected family across its component descendants, leaving the surrounding page unchanged.

Using fonts

Domino UI provides named font classes for the bundled families: Inter, Open Sans, Roboto, Source Sans 3, and IBM Plex Sans. Apply one to the application root for an app-wide choice, or combine it with dui-font-scope for a local choice.

The low-level CSS variables are also available when an application needs a custom stack. The scope preserves component sizing and weight tokens while applying the selected family, so components and form controls remain consistent.

Custom fonts

Load your webfont before applying it, preferably with WOFF2 files and font-display: swap. You can use any licensed webfont; Domino UI does not require the font to be bundled by the library.
