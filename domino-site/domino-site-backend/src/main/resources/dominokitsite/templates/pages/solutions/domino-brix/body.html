Domino Brix

A lightweight MVP framework for DominoKit apps that blends routing, presenters, slots, security, startup tasks, and an event bus into one cohesive runtime.

Routing & navigation

Drive navigation with declarative routes on presenters, history guards, and filters that keep the UI in sync with the browser URL.

Presenter lifecycle

Generated presenters and views manage slots, activation, and teardown so each page behaves predictably.

Events & startup tasks

Coordinate app boot with ordered startup tasks and keep modules decoupled with the built-in event bus and shared context.
