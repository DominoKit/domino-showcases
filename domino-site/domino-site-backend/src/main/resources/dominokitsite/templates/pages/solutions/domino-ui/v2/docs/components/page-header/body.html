PageHeader

A page-level variant of NavBar that provides a compact title and description treatment for documentation and application views.

Overview

PageHeader keeps NavBar composition while using an uppercase, reduced-opacity title and a lighter description with natural page spacing.

Use PageHeader for a page-level heading. Use NavBar when the content is a component or section header that should retain the standard navigation-bar height.
