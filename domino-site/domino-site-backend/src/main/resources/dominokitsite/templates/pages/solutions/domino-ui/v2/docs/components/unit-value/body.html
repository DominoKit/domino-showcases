UnitValue

Display a value together with its unit, title, and description in a compact, semantically grouped component.

Overview

The value inherits contextual color while emphasis changes its surface and border treatment.

Contextual colors change the value text, not the component background. Add dui_emphasis_subtle or dui_emphasis_minimal when a themed surface or border is needed.
